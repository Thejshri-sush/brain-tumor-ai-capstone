
# AI-Based Brain Tumour Segmentation, Classification and 3D Quantitative Analysis from MRI

## Project Overview

This project aims to develop an AI-based system for identifying brain tumour regions in MRI images, classifying tumour types, measuring tumour characteristics, and visualizing tumour regions in 3D.

## Project Modules

1. MRI data acquisition
2. MRI preprocessing
3. Tumour segmentation
4. Tumour classification
5. Quantitative tumour analysis
6. 3D visualization
7. Explainable AI
8. Web application and deployment

## Planned Technologies

- Python
- Deep learning
- FastAPI
- React

- Docker
