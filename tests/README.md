
# AI-Based Brain Tumour Analysis from MRI

## Project Overview
This project aims to perform brain tumour segmentation,
classification, quantitative analysis, and 3D visualization
using MRI data.

## Planned Modules
1. MRI data acquisition and preprocessing
2. Edge and feature extraction
3. Tumour segmentation
4. Tumour classification
5. Boundary and quantitative analysis
6. 3D visualization
7. Explainable AI
8. Data analytics
9. Application development and deployment

## Technology Stack
- Python
- Git and GitHub
- Deep learning
- FastAPI
- React
- Docker
